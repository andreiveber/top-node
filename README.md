# Сервер для контрольной работы — POST запросы с сохранением в JSON

## Описание проекта
Сервер на чистом Node.js (без фреймворков), который:
- Принимает **POST запросы** на `/data` с 4 параметрами
- Сохраняет данные в **JSON файл**
- Отображает все сохраненные записи

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск сервера
npm run dev
# или
npm run build
